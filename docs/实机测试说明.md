# 实机测试说明

遗产地图插件 —— 在 [中国遗产地图 STELE](http://stele.geogv.org/zhcn/) 的文保点位详情页，
叠加一张来自**高德地图 / 百度地图**的「开放时间 · 票价 · 地址」卡片。

> **先谢一句**：点位数据、坐标、名称全部来自 STELE（作者 [@pkkj](https://github.com/pkkj)，
> 独立维护、免费无广告）。本插件只是补上"这里的开放时间是多少"。
> 这是**非官方第三方工具**，与 STELE 官方无隶属关系。

---

## 一、加载扩展（约 1 分钟）

1. 打开 Chrome 或 Edge，地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角的 **开发者模式**
3. 点左上角 **加载已解压的扩展程序**
4. 选中本文件同级的 **`heritage-map-plugin/`** 目录（不是 zip）
5. 工具栏出现插件图标即成功

> ⚠️ 请把目录放在**不会被删除的固定位置** —— Chrome 每次启动都从那里加载。
> 如果你在 `chrome://extensions` 里点了「重新加载」，**必须再刷新一次 STELE 页面**，
> 否则当前标签页里跑的还是旧脚本。

## 二、配置 API Key

至少要配一个。**高德免费额度够用，5 分钟能搞定**，建议先配高德。

### 申请高德 Key（推荐）

1. 打开 <https://lbs.amap.com/> → 注册 → 实名认证
2. 控制台 → 应用管理 → 我的应用 → **创建新应用**（类型随便填）
3. 添加 Key：服务平台选 **「Web 服务 API」**（不是 JS API、不是 Mobile SDK）
4. 复制那串 Key 备用

### 申请百度 API Key（可选，作为备份）

> ⚠️ **应用类型必须选「服务端」，不是「浏览器端」。**
> 本插件调用的是百度的 **Web 服务 API**，只有服务端类型开放。
> 选「浏览器端」会得到 `status=240 APP 服务被禁用`。

1. 打开 <https://lbsyun.baidu.com/> → 注册 + 开发者认证
2. 控制台 → 应用管理 → 我的应用 → **创建应用**
3. 应用类型：**「服务端」**
4. IP 白名单填 **`0.0.0.0/0`**（插件没有固定出口 IP）
5. 服务列表里勾选 **「地点检索」**（Place API）
6. 复制 **访问应用（AK）**（别复制成旁边的「安全码（SK）」）
7. 若该 Key 开启了「SN 校验」，请改回普通校验（插件不做签名计算）

### 填入插件

1. 点工具栏的插件图标
2. 粘贴 Key
3. 点 **「测试 Key」** —— 注意：**它会先自动保存再测试**，
   并在结果里提示「已先保存当前填写的 Key」
4. 若有未保存的改动，面板上会显示黄色提示条

> 💡 **"测试通过"不等于"插件用上了"** —— 这是最容易踩的坑。
> 「测试 Key」测的是输入框里的值，只有写进存储才生效。
> 现在点测试会自动保存；若你手动改了下拉框，记得点「保存」。

## 三、开始测试

打开 <http://stele.geogv.org/zhcn/>，点地图上任意文保点位，等 1–2 秒，
详情面板底部出现卡片即成功。

建议按这几类各测一个：

| 类型 | 例子 | 预期 |
|---|---|---|
| 博物馆 / 景区 | 故宫、布达拉宫、云冈石窟 | 卡片显示开放时间、票价、地址 |
| 改名点位 ⭐ | 真觉寺金刚宝座、觉生寺、先农坛 | 显示「匹配到地图上的：北京石刻艺术博物馆（直线约 N 米）」 |
| 被机构征用 | 天主教大修院（现徐汇区政府院内） | 按实显示「徐汇区人民政府」的开放时间 |
| 冷门 / 未收录 | 某县区级文保 | 显示「暂未匹配」+ 两条跳转链接 |
| **文物组** | 莫高窟、上海交通大学早期建筑 | **不显示卡片**，请点进具体子项目 |

⭐ **改名点位是本插件的重点能力**，务必试一下。搜索框输入「真觉寺」即可定位。

## 四、看不到卡片 / 结果不对？

### 第 0 步（最常见）：刷新页面 + 清一次缓存

**扩展是在页面加载时注入的。** 先打开遗产地图、后安装/重载扩展的话，
当前标签页里根本没有插件 —— 必须 **F5 刷新**。

改了匹配逻辑之后还要**清缓存**：点插件图标 → **清除缓存**。
结果会缓存 7 天，旧结果不会自动失效（表现为"代码明明修好了、界面还是旧行为"）。

> 插件已做两层防护：① 缓存键带数据版本号，旧版本键读不到；
> ② 扩展安装/更新时自动清一次。但遇到"改了没生效"，先清缓存仍是最快的排查手段。

### 第 1 步：确认插件在页面上

`F12` → Console：

```js
HMP.debug.status()      // 当前路由、识别到的点位 id、已缓存点位
HMP.debug.inspect()     // 卡片/详情面板的 DOM 现场诊断
```

若提示 `HMP is not defined` → 插件没注入：先刷新页面；仍不行则检查扩展是否启用、
地址是否为 `http://stele.geogv.org/zhcn/...`。

### 第 2 步：按报错对照

| 现象 / 报错 | 原因 | 怎么办 |
|---|---|---|
| `status=240 APP 服务被禁用` | 百度 Key 类型选错，或没勾「地点检索」 | 改用**服务端**类型并勾选该服务 |
| `status=2 Parameter Invalid` | 请求缺定位参数（region / location / bounds 三者必居其一） | 插件已修正；若仍出现请反馈 |
| `status=5 AK Failure` | AK 不存在或没复制完整 | 重新复制 |
| `status=200 应用不存在` | 把「安全码（SK）」当成 AK 填了 | 填「访问应用（AK）」 |
| 高德 `INVALID_USER_KEY` | Key 不是「Web 服务 API」类型 | 重新申请正确类型 |
| 高德 `DAILY_QUERY_OVER_LIMIT` | 当日配额用完 | 明天再用，或改用百度 |
| 切到百度却是高德的结果 | ① 首选没保存 ② 百度没配 Key ③ 百度确实没这个点位 | 卡片上会写明具体原因，照它排查 |
| 点「在百度地图中搜索」落在海里 | 链接缺中心点 | 插件已修正（会带上校正后的坐标） |
| 「匹配到地图上的」是错的地方 | 名称相似但不同地点 | 把**这一行原文**发出来（见下） |
| 地图上写着"暂停营业"，插件却没说 | 该状态可能不在插件读取的字段里 | 见下方「排查状态字段」 |

### 第 3 步：反馈匹配错误

请带上**卡片上「匹配到地图上的：X（直线约 N 米）」那一整行**，再加上点位名称。

这一行包含匹配来源与距离，基本能定位到底是名称、地址还是坐标路径出的问题。
控制台里还会打印三路各自找到了什么，一并附上更好。

若命中了一处**「本体-子单元」**形式的地点（例如文保叫「商船会馆」，
却被匹配到「商船会馆-音乐剧《耋戏生》」），控制台会打印**候选次序**：

```
[HMP] 高德地图 候选次序（sim/score/是否子单元/距离）：
  商船会馆-音乐剧《耋戏生》(1.00/0.67/子/9m)  商船会馆(1.00/1.12/2m)
```

这一行能直接回答"本体到底在不在候选里、排第几、为什么输"。

### 排查状态字段

两家把"暂停营业/装修中"这类信号放在哪个字段，**不同接口与 POI 并不一致**，
所以插件会把所有**值**看起来像状态的字段打印一次（两家各一行）：

```
[HMP] 高德状态类字段：opentime_today=暂停开放
[HMP] 百度状态类字段：tag=暂停营业 | shop_hours=暂停营业
```

目前会纳入"可能不开放"提示的字段有：

| 位置 | 高德 | 百度 |
|---|---|---|
| 名称、描述 | `name`、短 `description` | 同左 |
| 状态标签 | `business.tag` | `detail_info.tag` |
| 开放时间本身 | `business.opentime_today` / `opentime_week` | `detail_info.shop_hours` |

**首选那家已有开放时间时**，插件仍会向另一家补一次**名称检索**（1 次请求），
专门看它有没有关闭标记——因为「暂停开放」经常只出现在其中一家身上。
这种情况下卡片会写明是哪一家标的：

> ⚠ 百度地图标记该点位可能不开放（含「暂停」），建议先电话确认再前往。

如果你在百度/高德地图上确实看到"暂停营业""暂停开放"之类的标记，而插件没有提示，
请把上面这两行诊断（或"没有这两行"这件事）反馈回来 ——
它决定了该去哪里取这个状态。

## 五、它到底怎么匹配的

三条路径并行跑，再交叉印证（而不是三选一）：

1. **名称检索** —— 文保名 / 从简介挖出的现用名 + 市级行政区
2. **地址检索** —— 行政区 + 门牌号（关键字会逐级放宽）
3. **坐标周边** —— 仿射校正后的坐标做 1 km 周边搜索

决策按**印证强度**分级：三重印证（名称=地址=坐标）> 两路印证 > 单一证据。
**单一证据不再直接拍板** —— "名字像"恰恰是最容易被骗的一路
（同名外地点位、同景区子单元、以及借用文保名的住宅小区）。

高德与百度**只是数据来源不同**，后续分析步骤完全一致；
首选那家没给开放时间时，会用另一家补上（卡片注明来源）。

完整推导、权重取值与实测数据见仓库根的 [`DESIGN.md`](../../DESIGN.md)。

│   ├── manifest.json
│   ├── content/                    注入到网站的脚本

**你的 Key 只存在本地浏览器**（`chrome.storage.local`），插件不向任何服务器上传。

### 彻底移除

`chrome://extensions` → 找到插件 → 移除，然后删除 `heritage-map-plugin` 目录即可
（不改动系统其它地方）。
